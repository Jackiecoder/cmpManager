# cmpManager 第一版

Kevin 与另外 5 位成员共同使用的公司工作台。公司 Owner / Admin 可以管理该公司的全部项目、账本和成员；普通成员必须按项目、账本单独授予 Viewer / Editor。不同公司的权限互不继承。登录后优先进入公司并显示已授权内容，个人空间仍独立可切换。创建项目或账本时可以直接选择加入成员，之后可以逐个调整。

项目权限覆盖分区、笔记、附件、项目待办和出入库；账本权限覆盖完整流水、报销和账本待办，单有项目权限不会获得财务金额。操作历史要求对记录当前归属及修改前后归属都有权限。公司普通成员看不到无归属的旧待办；由 Admin 为其补充项目/账本。旧公司 Editor / Viewer 迁移为普通成员，无自动资源授权，需要 Owner 逐项分配；业务记录、密码和历史署名保留。移出公司一并撤销所有资源授权。每次权限或业务修改与服务器署名的前后内容在同一事务写入日志。

数据维护提供单个个人空间、15 分钟、当前会话绑定的只读访问：管理员须重新验证密码并说明原因。所有读取均记录在被访问成员的个人空间，该成员可查看访问记录并随时结束权限。个人空间界面明确说明这个管理例外。服务器按空间隔离记录、日志、分区及跨记录关联，生产数据库 同时使用 FORCE RLS。个人空间不上传到公司共享 Drive。

## 界面设计

以手机日常录入为主，桌面展开为侧栏与内容区。参考 iPortfolio2 的主屏幕 Web App、清晰数字与安全区域适配。使用纸白 #FFFFFF、雾蓝 #F3F6FA、墨蓝 #18324C、湖蓝 #176B91、绿色 #197654、朱红 #BE4949。中文采用系统苹方字体，英文采用系统人文无衬线字体；正文 15px，标题 28px。信息左对齐，金额右对齐。

手机结构：顶部当前页面与新增动作；中部列表或项目记录；底部工作台 / 项目 / 财务 / 待办。项目详情按进度、沟通、待办、附件组织。工作台突出团队最近发生的工作，避免把每个功能都塞进相同的统计卡片。

## 数据

财务字段参考用户提供的《收支记账本》→《商会流水表》：日期、项目、事件、金额、人民币支付、转化美元、收支、支付状态、付款形式、入账状态、入账金额、负责人、备注。系统以原币金额 + 币种 + 手工确认的美元折算金额表达多币种；未知汇率不自行推算。余额为已录入收支净额，不等同于银行余额。原表仅作为字段参考，第一版不自动导入历史流水或改写原表。

项目包含负责人、状态、进度、期限及说明。每个项目可以有多个分区，例如“店家联系”“工厂一联系”；笔记、任务、附件和收支都可以关联分区，历史记录默认保留在“未分区”。分区只能在所属项目内改名，不能移动到其他项目。

笔记记录沟通日期、联系人、正文，并可在保存时选择不关联待办、关联同一项目的已有待办，或在同一事务中创建一个默认待办。默认待办的标题、负责人、截止日可以在保存前调整。笔记和待办的双向关联会显示在各自详情中；解除关联不会删除待办。任务包含责任人、截止日、完成状态；附件存入指定 Drive 文件夹，并关联所属项目、分区及上传人。

项目详情顶部以时间线代替负责人和百分比进度条。时间线按沟通日期倒序排列，显示分区名称、笔记标题、内容摘要及记录人；点击进入笔记。不同分区按创建顺序分配固定颜色，未分区用灰色。分区筛选同时作用于时间线。新增笔记的“加入项目时间线”默认勾选；旧笔记视为已加入。取消后仅从时间线隐藏，笔记和待办关联继续保留；修改该选项同样记录审计历史。

## 部署与边界

FastAPI + 原生 HTML/CSS/JS；本地 SQLite，生产强制 PostgreSQL。GCP Cloud Run 使用独立 cmpmanager 服务、独立数据库与数据库用户，可复用 iPortfolio2 所在 Cloud SQL 实例。真实业务数据、初始密码及 OAuth 凭据不进入 GitHub 或容器镜像。

Google Drive 个人云盘上传通过用户 OAuth refresh token，配置在 Secret Manager。未连接时明确提示，可以记录已有 Drive 文件链接。Google 文档说明个人云盘应使用用户 OAuth，服务账号不能拥有文件：https://developers.google.com/workspace/drive/api/guides/about-shareddrives 。Cloud Run 与 SQL 通过专属服务账号、Cloud SQL Client 和 Unix socket 连接：https://docs.cloud.google.com/sql/docs/postgres/connect-run 。

第一版是需联网的 PWA，无离线财务写入。成员姓名由管理员实际创建，不预填虚构人员。无业务记录硬删除接口；项目用暂停/完成归档状态。附件链接沿用原 Drive 权限。
